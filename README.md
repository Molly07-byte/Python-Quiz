# Python-Quiz
Interactive Python Quiz

**About the Project**
This project is an interactive quiz application developed using Python in Google Colab. It allows users to attempt quizzes, calculate scores, and track their performance.

**Features**
- Interactive quiz system  
- Multiple quiz categories
- Automatic score calculation
- Result storage using Pandas
- Leaderboard
- Performance analytics
  
**Technologies Used**
1. Python
2. Google Colab
3. Pandas
4. NumPy
5. JSON

**How to Run**
1. Open the Python_Quiz.ipynb notebook.
2. Click "Open in Colab".
3. Run the notebook cells in sequential order.
4. Follow the instructions to attempt the quiz.
5. View your results and performance.
